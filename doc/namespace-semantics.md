# Namespace semantics

Commerce's registered handlers and `internal/tenant/routes.go`/`scopes.go` define these rules. The [endpoint table](../README.md#endpoint-reference) gives the exact method, route, response kind, and public flag for every SDK method. Scope names below apply to API keys; org-claim bearer tokens and operators are governed by their identity provider and the server tenant guard. An API key with `<family>:write` can also read that family; `*` grants all families. GET needs `:read`, other methods need `:write`, except signed usage ingestion, which needs `usage:report`.

| Client namespace                                                                          | API-key scope family        | Auth and notable behavior                                                                                                                     |
| ----------------------------------------------------------------------------------------- | --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `organizations`                                                                           | `organizations`             | Creating/deleting a tenant requires an operator; org-scoped keys see their own tenant.                                                        |
| `products`                                                                                | `products`                  | Tenant-scoped catalog.                                                                                                                        |
| `plans`                                                                                   | `plans`                     | Compare uses `product_id`; feature/limit matrices can be null.                                                                                |
| `customers`                                                                               | `customers`                 | Tenant-scoped customer records.                                                                                                               |
| `contacts`                                                                                | `customers`                 | Contact IDs remain tied to their customer.                                                                                                    |
| `licenses`                                                                                | `licenses`                  | Validation is public with a license key and returns an invalid domain result rather than throwing for a validly formed failed validation.     |
| `activations`                                                                             | `activations`               | Activation and deactivation-by-key are public with a license key.                                                                             |
| `machines`                                                                                | `machines`                  | Update, delete, and decommission are operator-only because machines are shared across tenants.                                                |
| `subscriptions`                                                                           | `subscriptions`             | Lifecycle actions can return 409 `invalid_transition`.                                                                                        |
| `entitlements`                                                                            | `entitlements`              | Tenant-scoped feature grants.                                                                                                                 |
| `addons`                                                                                  | `addons`                    | Tenant-scoped add-on catalog and purchases.                                                                                                   |
| `usageMeters`                                                                             | `usage`                     | Meter definitions are scoped; use `usageReporter` for signed ingestion.                                                                       |
| `usage`                                                                                   | `usage`                     | Adjustments and credits are mutations and are not retried.                                                                                    |
| `usageReporter`                                                                           | `usage:report`              | API key required; signs exact bytes, with no mutation retry.                                                                                  |
| `orders`                                                                                  | `orders`                    | Checkout and fulfillment are the server routes; the Go SDK's update/pay routes do not exist.                                                  |
| `payments`                                                                                | `payments`                  | Refund/reconcile are mutations and are not retried.                                                                                           |
| `paymentMethods`                                                                          | `payments`                  | Token/reference only; checkout options share this scope. Raw card data is not collected.                                                      |
| `invoices`                                                                                | `invoices`                  | Issue/void replace the Go SDK's absent send route; PDF is streamed.                                                                           |
| `webhookEndpoints`                                                                        | `webhooks`                  | Create returns a one-time signing secret; provider callbacks are separate server routes.                                                      |
| `webhookEvents`                                                                           | `webhooks`                  | Retry is a mutation; verify received delivery signatures before handling.                                                                     |
| `applications`                                                                            | `applications`              | Applications own API keys and belong to an organization.                                                                                      |
| `apiKeys`                                                                                 | `api_keys`                  | Create/rotate return a one-time secret; keys cannot mint broader scopes.                                                                      |
| `offlineCertificates`                                                                     | `offline_certificates`      | Online verification is public with a certificate; local verification cannot know revocation.                                                  |
| `referralPrograms`, `referralCodes`, `referralEvents`                                     | `referrals`                 | Actions enforce lifecycle transitions.                                                                                                        |
| `commissionPlans`, `affiliates`, `affiliateLinks`, `affiliateEvents`, `commissionPayouts` | `affiliates`                | Actions enforce lifecycle transitions and can return 409.                                                                                     |
| `auditLogs`                                                                               | `audit_logs`                | CSV export is a raw response.                                                                                                                 |
| `system`                                                                                  | none                        | `/health` and signing-key retrieval are public; signing key returns direct JSON.                                                              |
| `gatewayConfigs`, `gatewayProviders`                                                      | `gateways`                  | Credentials are backend-only; webhook logs use the same family.                                                                               |
| `releases`                                                                                | `releases`                  | Published checksum, authorization, and token download have public/license-key or signed-token paths; uploads are multipart, downloads stream. |
| `notificationTemplates`, `notifications`                                                  | `notifications`             | Queue/retry are mutations; retry is allowed only for failed/bounced items.                                                                    |
| `applicationNotifications`                                                                | `application_notifications` | Feed and acknowledge are public routes authenticated by the handler with a license key or API key.                                            |

All non-public resources are tenant-checked. Foreign IDs return 404, foreign `org_id` input returns 403, missing auth returns 401, insufficient API-key scope returns 403 `insufficient_scope`, and invalid lifecycle actions commonly return 409 `invalid_transition`. `CommerceApiError` exposes status/code/details/request ID. An invalid license or offline certificate can instead be an accepted 422 domain result. Exact response envelopes and timestamp/integer behavior are in [Wire semantics](wire-semantics.md).

Only GET retries automatically on 429/502/503/504 and network failures; this applies to every namespace. POST/PATCH/DELETE, multipart upload, signed usage reports, issuance, refund, and other mutations are sent once. Caller abort and the overall timeout cover waits and fetch; raw streams keep the caller signal after headers. The optional per-client rate limiter does not replace the server's own 120-requests-per-minute API-key limit. For browser clients, use a short-lived bearer token; never bundle an API key or gateway credential.
